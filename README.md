# Colorir Kids

App web infantil para colorir imagens online, inspirado na experiência simples de sites como Colorir Online, mas com desenhos originais e interface própria.

## Funcionalidades

- Galeria com categorias de desenhos.
- Pintura por balde, pincel e borracha.
- Paleta infantil com seleção de cor.
- Desfazer, limpar, baixar em PNG e imprimir.
- Layout responsivo para computador, tablet e celular.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run build
```
